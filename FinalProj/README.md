Final Project: Music Room

It contains vinyl record, music note, and a speaker

Movements or Controls:
Music note - It moves upward automatically
Vinyl record - It moves 15 degrees to the left once the user clicks the left side of the mouse
Speaker - It changes the size depends on how the user control the mouse scroll. 
          Upsize - Scroll up
          Downsize - Scroll down
Exit the screen - press the 'Esc' to exit the Music room
